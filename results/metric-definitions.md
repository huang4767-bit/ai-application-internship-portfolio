# 指标定义与解释

本页集中说明公开摘要中的分母和含义。计数单位和阶段不同，不应相加成一个“数据总量”。

| 指标 | 定义 | 解释限制 |
|---|---|---|
| 1,187 | 较早知识整理阶段的措施初稿行数 | 不是当前运行库规模 |
| 492 | 2026-09-23 默认策略快照的记录数 | 与初稿不是可证明的原样筛选关系 |
| 438/492 | 运行库措施正文可在初稿中精确匹配的条数 | 只按正文匹配；不等于审批追踪 |
| 325/492 | 风险大类、风险项、子风险项和正文四字段同时匹配的条数 | 更严格的字段匹配口径 |
| 7,450 | 固定候选原始评测中的猪群案例数 | 不是用户数 |
| 10,516 | 原始评测中的来源问题数 | 与猪群案例不是同一计数单位 |
| 7,303 / 10,121 | 猪群案例 / 问题的严格共同评测集 | 用于双参照一致率统计 |
| 79.72% | 严格共同集上两个参考模型彼此之间的首选一致率 | 不是被测模型与参考模型的一致率，也不是业务正确率或人工准确率 |
| 22 | K1 实验中筛选的补充参考知识条目 | K1 不改变固定候选的召回 |
| 7,233/7,450 | 有知识关联的案例数 / 原始案例数 | 覆盖情况，不是效果提升 |
| 44,700 | 六型号 × 7,450 案例的 K1 原始排序调用数 | 不是独立案例数 |
| 7,182 / 9,671 | 统一严格集中的案例 / 问题数 | 用于对应的 K1 汇总 |
| 247 passed / 8 skipped | 2026-11-17 策略归档副本离线检查 | 后续个人归档核查，不是实习成果或业务验收 |

相关定义及严格集区分见[评测说明](../cases/risk-recommendation/evaluation.md)和[交付边界](../cases/risk-recommendation/delivery.md)。
