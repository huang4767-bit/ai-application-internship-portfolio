# AI 应用开发作品集

面向 AI 应用开发、RAG 与 Agent 工程岗位的项目作品集，主案例是养殖风险知识库与猪群措施推荐。

## 主案例：养殖风险知识库与措施推荐

我负责把业务资料整理成措施库，并开发推荐链路：系统结合风险问题和猪群阶段、季节、天气等背景，从审核更新后的措施库中召回、筛选和排序，输出猪群措施表及问题关联表。后续我固定输入与候选开展模型比较和补充知识实验。**最终选定模型已上线。**
